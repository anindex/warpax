# Reproducing "Observer-robust energy condition verification for warp drive spacetimes"

This guide maps every figure, table and quoted number in the paper
([arXiv:2602.18023](https://arxiv.org/abs/2602.18023)) to the script that produces
it, at **warpax v1.4.0**. The manuscript itself names no script; this file is where
that mapping lives.

Releases are archived at [10.5281/zenodo.18715933](https://doi.org/10.5281/zenodo.18715933).
No external datasets are required.

## Running everything

```bash
export PYTHON=$(uv run which python)
bash reproduce_all.sh
```

Stages run individually, and in this order:

```bash
bash reproduce_all.sh --stage core        # [K*] every number quoted in the text
bash reproduce_all.sh --stage ablation    # the Rodal DEC sweeps, Appendix D
bash reproduce_all.sh --stage figures     # every .pdf under figures/
bash reproduce_all.sh --stage enclosures  # [E1] opt-in; hours of branch-and-bound
bash reproduce_all.sh --stage gate        # the consistency checks below
```

`--keep-cache` skips the cache wipe and recomputes only what is missing.

The `enclosures` stage is separate because it is interval branch-and-bound over
120,000 boxes and takes hours. Everything else finishes in minutes on a CPU.

**All published numbers are CPU-computed.** On the Blackwell (sm_120) build, 68 tests
fail on the GPU backend and are registered as expected failures there, among them the
Type III/IV classification tests and the 50-digit cross-check, because the affected
vendor kernels are the ones backing the general eigensolver and the SVD. The
curvature chain is unaffected, and the GPU timings quoted in the paper are for it.

## The two gates

`scripts/check_paper_numbers.py` runs in the `gate` stage and fails the build on any
mismatch. It does two things.

1. **Prose against artifacts.** Every number quoted in the manuscript's running text
   is matched by an explicit regex against the table or the `results/*.json` it came
   from. The checks are written out one at a time, deliberately: a generic
   "find every number in the prose" scanner cannot tell a quoted result from a
   parameter, and the failure mode this replaced was prose that had drifted from a
   regenerated table by one revision.

2. **Artifact staleness.** Every watched artifact must postdate every file under
   `src/warpax/` and `scripts/`. A published number older than the code that produced
   it fails the gate. The check excludes itself, so editing the gate does not condemn
   the data it is checking.

A missing artifact is a failure, not a skip: on a wiped `results/` a check that
skips on absence passes while checking almost nothing.

## Reproducibility record

Re-running from an empty `results/` on a second, independent pass reproduces all four
certified enclosures to the last printed digit, and regenerates 28 of the 31 shipped
tables byte for byte. The three that differ are the two averaged-condition tables,
whose affine window and quadrature were corrected, and the convergence ladder that
follows them.
